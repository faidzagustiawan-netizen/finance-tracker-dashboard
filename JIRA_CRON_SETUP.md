## 📋 SETUP STEPS

### 1️⃣ Configure Jira Credentials

Edit script: `~/.hermes/scripts/jira_daily_summary.sh`

```bash
nano ~/.hermes/scripts/jira_daily_summary.sh
```

Find these lines & update dengan data kamu:

```bash
JIRA_DOMAIN="your-domain.atlassian.net"
JIRA_EMAIL="your-email@company.com"
JIRA_TOKEN="your_api_token"
JIRA_PROJECT="FIN"
```

**Get from:**
- Domain: Jira URL (contoh: mycompany.atlassian.net)
- Email: Email akun Jira
- Token: Jira Settings → Security → API tokens
- Project: Project key (FIN, TRACK, etc)

Save (Ctrl+X → Y → Enter)

### 2️⃣ Test Manual Run

```bash
~/.hermes/scripts/jira_daily_summary.sh
```

Expected output:
```
✅ Daily summary created
```

### 3️⃣ Check Cron Job Status

```bash
hermes cron list
```

Should show:
```
✓ jira-daily-finance-summary
  Schedule: 0 8 * * * (daily 8 AM)
  Next run: 2026-09-04T08:00:00+08:00
```

## ⚙️ CUSTOMIZE

### Change Schedule

Edit cron expression:

```bash
hermes cron update 18d574466417 --schedule "0 9 * * *"  # 9 AM instead
hermes cron update 18d574466417 --schedule "0 */6 * * *" # Every 6 hours
```

### Add Conditional Logic

Example: Only create issue if expense > Rp 500,000

```bash
if [ $EXPENSE -gt 500000 ]; then
  # Create issue only if high expense
  $PYTHON $FINANCE_DIR/jira_client.py create ...
fi
```

### Add Notifications

Send alert to WhatsApp/Telegram after creation:

```bash
# After issue creation
hermes send --to whatsapp:62895397133738 "Daily summary created: $SUMMARY"
```

## 🔍 TROUBLESHOOTING

### Issue not created

Check logs:
```bash
~/.hermes/scripts/jira_daily_summary.sh 2>&1 | tee /tmp/jira_debug.log
```

### Authentication error

Verify Jira credentials:
```bash
curl -u "email@company.com:TOKEN" \
  https://your-domain.atlassian.net/rest/api/3/myself
```

### API endpoint error

Check Finance Tracker is running:
```bash
curl http://127.0.0.1:5000/api/balance
```
